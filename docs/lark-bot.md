# 飞书机器人配置指南

Orca 支持通过飞书应用机器人进行事件通知推送和交互式命令查询。

## 功能概览

### 通知推送（被动）

当以下事件发生时，Orca 自动向飞书群发送卡片消息：

- 新事件创建（告警触发）
- 新调查创建（Agent 发现问题）
- 调查解决（Agent 得出结论）

### 交互命令（主动）

在飞书群中 @机器人 或私聊机器人，可执行以下命令：

| 命令 | 说明 |
|------|------|
| `调查列表` | 列出进行中的调查 |
| `已解决` | 列出已解决的调查 |
| `全部调查` | 列出所有调查 |
| `查看 <ID>` | 查看调查详情和时间线（支持 ID 前缀匹配，输入前 8 位即可） |
| `事件列表` | 列出最近 10 条事件 |
| `帮助` | 显示可用命令 |

## 创建飞书应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，点击 **创建企业自建应用**
2. 填写应用名称（如 `Orca`）和描述
3. 创建完成后，在应用详情页记录 **App ID** 和 **App Secret**

## 配置权限

进入应用 → **权限管理**，开通以下权限：

| 权限 | 说明 |
|------|------|
| `im:message:send_as_bot` | 以应用身份发消息（通知推送） |
| `im:message.receive_v1:readonly` | 读取用户发给机器人的消息（交互命令） |

> 权限 `im:message.receive_v1:readonly` 会在添加事件订阅时自动申请，无需手动查找。

## 配置事件订阅

进入应用 → **事件与回调** → **事件配置**：

1. **订阅方式**：点击编辑，选择 **使用长连接接收事件**（推荐）
   - 无需公网域名或回调 URL
   - Orca 启动时自动通过 WebSocket 连接飞书服务器接收消息
2. 点击 **添加事件**，搜索 `接收消息` 或 `im.message.receive_v1`
3. 添加该事件，确认所需权限已开通

## 启用机器人能力

进入应用 → **应用能力** → **机器人**，开启机器人能力。

## 发布应用

进入应用 → **版本管理与发布**，创建版本并提交审核（企业内部应用通常自动通过）。

## 添加机器人到群

在飞书客户端：

1. 打开目标群 → 群设置 → **群机器人**
2. 点击 **添加机器人**，找到你创建的应用并添加
3. 记录该群的 **Chat ID**（可通过飞书开放平台 API 调试台获取，或在群设置中查看）

### 获取 Chat ID

方法一：使用飞书开放平台 [API 调试台](https://open.feishu.cn/api-explorer/cli_xxx?apiName=list&from=op_doc&project=im&resource=chat&version=v1)，调用 `GET /open-apis/im/v1/chats` 接口查看机器人所在的群列表。

方法二：在群设置的群信息中，部分版本会直接显示群 ID。

## 在 Orca 中配置

1. 打开 Orca Web 界面 → **通知** 页面
2. 填写配置：
   - **App ID**：飞书应用的 App ID
   - **App Secret**：飞书应用的 App Secret
   - **Chat ID**：目标群的 Chat ID（`oc_` 开头）
3. 开启 **启用** 开关
4. 点击 **测试发送**，确认群里收到测试消息
5. 保存配置

保存后 Orca 会自动启动 WebSocket 长连接，开始接收群内 @消息。

## 验证

### 验证通知推送

触发一条测试告警（如通过 Uptime Kuma），确认飞书群收到事件通知卡片。

### 验证交互命令

在飞书群中发送：

```
@Orca 帮助
```

应收到可用命令列表的卡片回复。

```
@Orca 调查列表
```

应收到进行中调查的列表。

```
@Orca 查看 abc123
```

应收到对应调查的详情和时间线（`abc123` 替换为实际调查 ID 前几位）。

## 常见问题

### 机器人没有回复消息

1. 确认应用已发布且审核通过
2. 确认已添加 `im.message.receive_v1` 事件订阅，且订阅方式为"长连接"
3. 确认 Orca 的通知配置已启用且 App ID / App Secret 正确
4. 查看 Orca 后端日志，搜索 `Bot:` 关键字确认 WebSocket 连接状态

### 群里收不到通知

1. 确认 Chat ID 填写正确（`oc_` 开头）
2. 确认机器人已添加到该群
3. 使用"测试发送"功能验证连通性
4. 确认应用有 `im:message:send_as_bot` 权限

### 只需要通知不需要交互命令

只配置通知即可，不添加 `im.message.receive_v1` 事件订阅。Orca 在没有事件订阅时只会单向推送通知，不会建立 WebSocket 连接。
